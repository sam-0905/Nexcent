# Nexora – Modern Landing Page

A modern, responsive landing page built as part of an SDE-1 frontend development assessment.

The project recreates the provided Figma design using **Next.js, React, TypeScript, and Tailwind CSS**, with a focus on reusable components, clean architecture, structured content, responsive design, and maintainable code.

## 🚀 Live Demo

🔗 **Live Website:** https://nexoracent.netlify.app/

🔗 **GitHub Repository:** https://github.com/sam-0905/Nexcent

---

## 📌 Project Overview

Nexora is a modern business/agency landing page designed to showcase services, achievements, testimonials, marketing content, and company information.

The implementation focuses on translating the provided Figma design into a responsive web application while following modern frontend development practices.

### Key Goals

- Recreate the provided Figma design closely
- Build a fully responsive landing page
- Use reusable and modular React components
- Separate content from presentation
- Store page content in structured TypeScript data
- Follow Next.js App Router best practices
- Maintain a clean and scalable project structure
- Optimize the application for production deployment

# 🚀 Getting Started

- Clone the repository:
``
git clone https://github.com/YOUR_USERNAME/Nexcent.git
``
Navigate to the project:
```
cd Nexcent/nexora
```
### Install dependencies:
```
npm install

Start the development server:

npm run dev
```
Open:
```
http://localhost:3000
📦 Production Build

Create a production build:

npm run build
```
## Start the production server:
````
npm run start
🌐 Live Demo
````
